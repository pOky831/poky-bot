# pOky Bot

pOky - Ein Discord Bot mit Dashboard, Moderation, Tickets und mehr.

## Setup

1. Copy `.env.example` to `.env`.
2. Fill in your Discord credentials:
    - `DISCORD_TOKEN`
    - `CLIENT_ID`
    - `GUILD_ID` (your test server id)
3. Install dependencies:

```bash
npm install
```

4. Start in dev mode:

```bash
npm run dev
```

If the bot starts successfully, test `/ping` in your Discord test server.
